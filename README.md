# Python Activity-Based Learning (ABL)

This repository contains 10 Python case-study projects for I B.Tech Python Programming, organized with one project per folder.

## Syllabus coverage
- **Unit I:** computational thinking, algorithms, pseudocode, flowcharts, variables, data types, input/output, type conversion, operators, expressions.
- **Unit II:** conditions, loops, break/continue, strings and string methods.
- **Unit III:** lists, tuples, sets, traversal and operations.

## Projects
1. `01_student_grade_calculator/` — marks and grade calculation
2. `02_electricity_bill_calculator/` — tiered electricity bill
3. `03_employee_salary_calculator/` — gross and net salary
4. `04_attendance_calculator/` — attendance percentage and eligibility
5. `05_library_fine_calculator/` — overdue fine calculation
6. `06_shopping_bill_generator/` — itemized bill using lists and loops
7. `07_atm_simulation/` — menu-driven ATM simulation
8. `08_student_marks_analysis/` — list-based marks statistics
9. `09_password_strength_checker/` — string validation practice
10. `10_student_club_management/` — set operations for club membership

## Folder contents
Each project folder contains:
- `main.py` — runnable Python source code
- `README.md` — documentation, algorithm, pseudocode, sample test cases and conclusion
- `flowchart.mmd` — Mermaid flowchart source
- `test_cases.md` — test inputs and expected outputs
- `screenshots/` — three illustrative SVG output previews per project, indexed in `screenshots/README.md` (these are previews, not real terminal captures)

## Run a program
Open a terminal in the chosen project folder and run:

```bash
python main.py
```

These are syllabus-aligned learning examples. Example fee rates and eligibility thresholds are assumptions for demonstration and should be adjusted to match any official requirements supplied by the faculty.

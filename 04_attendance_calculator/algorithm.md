# Algorithm: Student Attendance Percentage Calculator

1. Start.
2. Read the total number of classes conducted.
3. Read the number of classes attended.
4. If total classes are zero or negative, display an error message.
5. Else if attended classes are negative or greater than total classes, display "Invalid attendance details".
6. Otherwise:
   - Calculate attendance percentage = (attended classes / total classes) × 100.
   - Display the attendance percentage rounded to two decimal places.
   - If percentage is at least 75, display "Eligible".
   - Otherwise, display "Not eligible".
7. Stop.

**Note:** 75% is an example eligibility threshold. Follow your college's attendance rule if it is different.

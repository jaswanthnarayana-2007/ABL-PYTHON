# Algorithm: Library Late-Fee Calculator

1. Start.
2. Read the number of days the book is overdue.
3. If the number of days is negative, display "Invalid number of days".
4. Else if days = 0, display "No fine".
5. Else if days are at most 5, calculate fine = days × Rs. 2.
6. Otherwise, calculate fine = (5 × Rs. 2) + ((days − 5) × Rs. 5).
7. Display the calculated fine in rupees.
8. Stop.

**Note:** The fine rates are sample rules for this project.

# Algorithm: Employee Salary Calculator

1. Start.
2. Read the employee's name.
3. Read the basic salary.
4. If the basic salary is negative, display "Invalid salary".
5. Otherwise:
   - Calculate HRA = 20% of basic salary.
   - Calculate DA = 10% of basic salary.
   - Calculate PF deduction = 12% of basic salary.
   - Calculate gross salary = basic salary + HRA + DA.
   - Calculate net salary = gross salary − PF deduction.
6. Display the employee's name, basic salary, HRA, DA, PF deduction, gross salary, and net salary.
7. Stop.

**Note:** HRA, DA, and PF percentages are illustrative assumptions. Use the rates given by your lecturer if they differ.
